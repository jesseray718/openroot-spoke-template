## Reporting a Vulnerability

Use this section to tell people how to report a vulnerability.

Tell them where to go, how often they can expect to get an update on a
reported vulnerability, what to expect if the vulnerability is accepted or
declined, etc.

**For security issues in hardware designs (ferrocement, thermal systems):**
- Contact: jrm8908@proton.me
- Expected response time: 48 hours
- Please include detailed description and potential impact

**For security issues in software:**
- Open a private security advisory: https://github.com/jesseray718/[repo]/security/advisories
- Or email: jrm8908@proton.me with "[SECURITY]" in subject line
